# 커피 브루잉 앱

`커피 필드 매뉴얼`(커피 종합 가이드, 14개 챕터)의 내용을 실제로 써먹을 수 있는 도구로 옮긴 웹 앱입니다.
빌드 도구나 서버 없이 `index.html`을 브라우저로 열면 바로 동작합니다.

## 화면

| 탭 | 하는 일 | 근거 챕터 |
| --- | --- | --- |
| **추출 레시피** | 방식(핸드드립·프렌치프레스·에스프레소·콜드브루)과 원두 양을 정하면 물 양·온도·분쇄도·푸어 스케줄을 계산하고, 단계별 브루잉 타이머를 돌립니다. | 06 그라인딩, 07 브루잉 비율, 08 물과 온도 |
| **카페인** | 마신 음료를 기록해 1일 권장 한도 400mg 대비 섭취량과 최근 7일 추이를 보여줍니다. | 11 카페인과 건강, 12 음료의 종류 |
| **원두 선반** | 로스팅 날짜로 디게싱(2~14일)과 권장 소비 기한(2~4주)을 계산합니다. | 03 산지, 04 가공, 05 로스팅, 09 보관법 |
| **커핑 노트** | 5개 항목을 6.00~10.00점으로 평가해 100점으로 환산하고, 80점(스페셜티 기준) 도달 여부를 표시합니다. | 10 테이스팅, 13 스페셜티 등급 |
| **가이드** | 방식별 기준값, 로스팅 단계, 음료 구성 비율, 과다/과소추출 진단표. | 전 챕터 요약 |

## 주요 동작

- **비율 계산** — 원두 g × 비율 = 물 ml. 잔 수(240ml 기준)를 고르면 필요한 원두 양을 역으로 계산합니다.
- **푸어 스케줄** — 핸드드립은 블루밍(원두 2배 물, 30초) → 60% → 100% 순으로 각 단계에서 부어야 할 누적/추가 물량을 표시합니다.
- **타이머** — 단계가 바뀔 때 짧은 알림음이 울리고, 현재 단계가 강조됩니다.
- **콜드브루** — 타이머 대신 침출 시각을 기록해 12/18/24시간 뒤 완료 시각을 계산합니다.
- **카페인 추정** — 에스프레소 1샷 63mg, 드립 240ml 95mg 기준. 로부스타는 아라비카의 2배, 블렌드는 1.3배로 보정합니다. 어디까지나 추정치입니다.

## 실행

```bash
# 그냥 파일로 열기
open coffee-app/index.html        # macOS
xdg-open coffee-app/index.html    # Linux

# 또는 로컬 서버로
npx http-server coffee-app -p 8080
```

## 폰에 설치하기 (PWA)

HTTPS로 서빙되는 주소에 접속하면 홈 화면에 설치할 수 있고, 설치 후에는 오프라인에서도 동작합니다.

- **iPhone (Safari)** — 공유 버튼(□↑) → `홈 화면에 추가`
- **Android (Chrome)** — 우측 상단 ⋮ → `앱 설치`. 설치 가능한 상태면 앱 상단에 `홈 화면에 추가` 버튼도 나타납니다.

`manifest.webmanifest`가 이름·아이콘·시작 URL을, `sw.js`가 앱 셸 캐시(캐시 우선)와 구글 폰트
캐시(stale-while-revalidate)를 담당합니다. 서비스 워커는 보안 컨텍스트에서만 등록되므로
`file://`로 열면 설치·오프라인 기능 없이 앱만 동작합니다.

배포 예시 — GitHub Pages: 저장소 Settings → Pages → Deploy from a branch로 브랜치를 지정하면
`https://<사용자>.github.io/<저장소>/coffee-app/` 에서 열립니다.

## 구조

```
coffee-app/
├── index.html              화면 마크업(탭 5개)
├── manifest.webmanifest    PWA 매니페스트(이름·아이콘·시작 URL·바로가기)
├── sw.js                   서비스 워커(앱 셸 캐시, 오프라인 실행)
└── assets/
    ├── css/
    │   └── style.css       매뉴얼의 디자인 토큰(색·타이포·다크모드)을 그대로 사용
    ├── icons/              앱 아이콘(192 · 512 · maskable · apple-touch)
    └── js/
        ├── data.js         매뉴얼에서 뽑아낸 상수: 방식·로스팅·음료·카페인·커핑·보관
        ├── store.js        localStorage 저장소, 날짜/DOM 유틸
        ├── brew.js         레시피 계산 · 타이머 · 침출 기록
        ├── caffeine.js     섭취 기록 · 게이지 · 7일 차트
        ├── beans.js        원두 등록 · 신선도 계산
        ├── cupping.js      커핑 점수 · 향미 태그 · 노트
        ├── guide.js        참조표 렌더링
        └── app.js          탭 전환 · 테마 · 토스트 · 설치 프롬프트
```

의존성이 없는 순수 HTML/CSS/JS이며, 스크립트는 전역 네임스페이스(`CoffeeData`, `Store`, `BrewView` …)로
연결되어 `file://`로 열어도 그대로 동작합니다.

## 데이터 보관

모든 기록(추출 설정, 카페인 로그, 원두, 커핑 노트, 테마)은 브라우저 `localStorage`에만 저장되며
외부로 전송되지 않습니다. 브라우저가 저장을 막는 환경에서는 세션 동안 메모리에만 유지됩니다.

## 참고

수치는 매뉴얼의 일반적인 기준값입니다. 원두·장비·취향에 따라 조정해 쓰는 것을 전제로 합니다.
