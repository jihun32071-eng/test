# 디지바이스 제로 (DIGIVICE ZERO)

의존성 없는 단일 HTML 파일로 만든 디지몬 스타일 육성 + 턴제 배틀 게임.
`index.html`을 브라우저로 열면 바로 실행된다.
안드로이드 앱으로 감싼 버전은 [`../app`](../app) 에 있다.

## 게임 루프

1. **부화** — 디지타마가 부화하면 이름을 지어 준다.
2. **육성** — 먹이·청소·칭찬·훈련으로 배고픔, 기력, 기분, 규율, 무게를 관리한다.
3. **진화** — 형태별 체류 시간을 채우면 진화한다. 어떤 모습이 되는지는 그동안의 육성 결과가 결정한다.
4. **모험** — 4개 지역에서 야생 디지몬과 싸우고 보스를 잡아 지역을 제패한다.

## 진화 분기

유아기Ⅱ(토톳몬)에서 성장기로 갈 때 갈림길이 생긴다.

| 조건 | 진화 |
|---|---|
| 케어미스 ≤ 1, 훈련 3회 이상, 힘 위주 | 불씨몬 (불) |
| 케어미스 ≤ 2, 방어 훈련 2 이상 | 쇳조각몬 (강철) |
| 케어미스 ≤ 3, 기분 4 이상 | 새싹몬 (풀) |
| 케어미스 ≥ 5 | 그늘몬 (어둠) |
| 그 외 | 물방울몬 (물) |

이후 성숙기 → 완전체 → 궁극체로 이어지며, 케어미스가 쌓이면 어둠 계열로 타락하고
(그늘몬은 잘 돌보면 정규 계열로 복귀할 수 있다) 전투 승수가 모자라면 궁극체에 도달하지 못한다.
총 23종 + 야생 전용 6종을 수록했다.

## 케어 시스템

- 배고픔·기력이 0인 채로 1시간(게임 내) 방치하면 **케어미스** 1회
- 밤에 불을 켜 둔 채로 재우면 케어미스
- 배설물을 4개 이상 방치하면 질병에 걸리고, 12시간 방치하면 소멸
- 케어미스 15회면 소멸 → 다음 세대(GEN)의 알을 받는다

## 배틀

- 속성 상성: 불 → 풀 → 물 → 불, 강철 → 풀·어둠, 어둠 → 물 (유리 1.6배 / 불리 0.65배)
- 속도가 높은 쪽이 선공할 확률이 높다
- 22종의 기술 (피해·회복·방어·흡수)
- 패배하면 부상, 승리하면 스탯 성장과 아이템 획득

## 기술 메모

- 스프라이트는 16×16 픽셀 격자를 문자열로 정의하고 팔레트를 갈아 끼워 재사용한다 (`TPL` + 각 형태의 `pal`)
- 캔버스는 160×120 내부 해상도로 픽셀 아트만 그리고, 모든 텍스트는 DOM 오버레이가 담당한다
- 진행 상황은 `localStorage`에 4초마다 자동 저장되고, 자리를 비운 시간은 최대 8시간(게임 내)까지 반영된다
- 실제 1초 = 게임 2분 (하단 속도 버튼으로 x1 / x2 / x4)
