## 1. 기본 구성

아침에 30초 안에 훑고 바로 움직일 수 있는 항목만 담습니다.

| 항목 | 내용 | 판단 기준 |
|---|---|---|
| 오늘 일정 | 첫 약속 시간, 그때까지 남은 시간 | 지금 나가야 하나? |
| 날씨 | 우산·겉옷 필요 여부 중심 | 뭘 챙기나? |
| 오늘 할 일 3가지 | 전체 목록이 아닌 상위 3개만 | 오늘 뭘 끝내나? |
| 덕질 일정 | 아래 2번 참고 | 오늘 밤 뭘 보나? |
| 어제 기록 | 수면 시간, 운동, 컨디션 | 오늘 페이스 조절 |
| 한 줄 문장 | 인용구 또는 오늘의 의도 | — |

**운영 원칙**

- 항목은 6개 이하로 유지
- "읽고 나서 할 일이 정해지는가"를 기준으로 넣고 뺄지 결정
- 주가·일반 뉴스처럼 봐도 행동이 안 바뀌는 항목은 제외

## 2. 덕질 일정 섹션

### 표시 형식

각 팀마다 두 줄만:

```
[팀명]  어제 결과 → 다음 경기 D-day
```

새벽 경기가 많아서 "어제 결과 + 다음 경기까지 남은 일수" 형태가 가장 실용적입니다.

### 팀별 특성

| 대상 | 일정 확정도 | 확인 시점 | 소스 |
|---|---|---|---|
| 레알 마드리드 | 높음 (시즌 단위 확정) | 주 1회면 충분 | 라리가 공식, 챔피언스리그 |
| LG 트윈스 | 중간 (우천취소·재편성 잦음) | **당일 아침 필수** | KBO 공식, 구단 홈페이지 |
| T1 | 중간 (주 단위 대진 공개) | 주 1회 | LCK 공식, lolesports.com |
| 리센느 | 낮음 (라이브 예고 없음) | 브리핑 제외 권장 | YouTube 알림 설정 |

**리센느 관련 메모**
유튜브 라이브를 예고 없이 새벽에 켜는 편이라 브리핑에 넣기 어렵습니다. 대신 이렇게 나누는 걸 권합니다.

- **라이브 방송** → 유튜브 채널 알림 켜기 (유일한 방법)
- **음악방송·컴백·팬미팅** → Blip, 최애돌 같은 스케줄 앱에서 확인 후 캘린더에 수동 등록
