# 산길 난이도 도감

국내 산 39곳, 58개 등산 코스를 **하나의 난이도 지수**로 환산해 비교하는 정적 웹사이트입니다.
표고만으로는 드러나지 않는 체감 난도를 거리·누적 상승고도·지형으로 계산합니다.

## 난이도 지수

```
지수 = √( 2 × 누적상승(m) × 거리(km) ) × 지형계수
```

미국 셰넌도어 국립공원의 하이킹 난이도 산정 방식을 미터법에 맞춰 변형했습니다.

| 등급 | 지수 | 대상 | 소요시간 |
|---|---|---|---|
| 입문 | 0 ~ 49 | 산행 경험이 없어도 가능 | 2시간 내외 |
| 초급 | 50 ~ 89 | 평소 걷기 운동을 하는 성인 | 3~4시간 |
| 중급 | 90 ~ 149 | 월 1회 이상 산행하는 사람 | 4~6시간 |
| 상급 | 150 ~ 219 | 체력 훈련이 된 정기 산행자 | 6~9시간 |
| 최상급 | 220 이상 | 장거리 산행 경험자 · 1박 검토 | 9시간 이상 |

지형계수: 흙길·완경사 ×1.0 · 돌계단·너덜 ×1.1 · 암릉·철계단 ×1.2 · 로프·위험구간 ×1.3

예상 소요시간 `= (거리 ÷ 3km/h + 누적상승 ÷ 450m/h) × 지형 보정` — 휴식 포함 일반 등산객 기준.

## 실행

빌드 도구 없이 브라우저에서 `index.html`을 바로 열면 됩니다.

```bash
python3 -m http.server 8000   # http://localhost:8000
```

## 구조

```
index.html                 페이지 본문
assets/css/style.css       디자인 토큰 · 레이아웃 (라이트/다크 모두 지원)
assets/js/data.js          산 · 코스 데이터, 지형계수, 등급 정의
assets/js/app.js           지수 계산, 필터·정렬, 상세 시트, 등고선 배경
tools/build-artifact.py    단일 HTML 파일로 묶는 빌드 스크립트
```

## 데이터 추가하기

`assets/js/data.js`의 `MOUNTAINS` 배열에 항목을 넣으면 지수·등급·소요시간은 자동 계산됩니다.

```js
{
  id: "gwanaksan", name: "관악산", elev: 632,
  region: "수도권", area: "서울 관악 · 경기 안양",
  park: "", season: "사계절",
  summary: "한 줄 소개",
  courses: [
    { name: "서울대 ~ 연주대 왕복", dist: 7.2, gain: 560,
      shape: "왕복", terrain: "rock", note: "가장 대중적인 코스" }
  ]
}
```

- `region` 은 `·` 로 여러 지역을 묶을 수 있습니다(예: `"충청·전라"`). 필터 칩이 자동 생성됩니다.
- `terrain` 은 `earth` / `stone` / `rock` / `danger` 중 하나입니다.
- 산의 대표 등급은 **가장 수월한 코스** 기준이며, 카드에는 최고 난도 코스도 함께 표시됩니다.

## 데이터에 대한 주의

거리와 누적 상승고도는 공개된 탐방로 정보와 일반적인 산행 기록을 참고해 정리한 **근사값**입니다.
측정 기기와 실제 경로에 따라 달라지며, 난이도 지수는 산끼리 비교하기 위한 상대적 척도일 뿐
안전을 보장하지 않습니다. 산행 전 [국립공원공단](https://www.knps.or.kr)의 탐방로 개방 여부·입산
통제 시각과 기상 정보를 확인하세요. 산악사고 신고는 119입니다.
