API 챗봇

폰에 설치하기

Anthropic API 로 대화하는 안드로이드 앱입니다. 아래 세 단계면 끝나요.

안내

안드로이드 폰에서 열어 주세요

APK 는 안드로이드 전용 설치 파일입니다. 아이폰에는 설치할 수 없어요.

이 페이지 주소를 안드로이드 폰으로 보내 그쪽 브라우저에서 여세요.

1단계

APK 내려받기

폰 브라우저에서 아래 버튼을 누르면 설치 파일이 내려받아집니다.

api-chatbot.apk 받기 약 16 MB

항상 최신 빌드를 가리키는 주소입니다. 릴리스 페이지에서 받아도 됩니다.

2단계

설치하기

내려받은 파일을 누르면 설치가 시작됩니다. 처음이라면 허용을 한 번 물어봅니다.

  1. 알림창이나 다운로드 폴더에서 api-chatbot.apk 를 누릅니다
  2. 이 출처의 앱 설치 허용 이 뜨면 켜 줍니다 (설정 → 앱 → 특별한 앱 접근)
  3. 돌아와서 설치 를 누릅니다

서명 없는 디버그 빌드라 플레이 프로텍트 경고가 뜰 수 있습니다. 무시하고 설치 를 누르면 됩니다. 플레이스토어 앱과는 따로 설치돼요.

3단계

API 키 넣기

앱을 처음 켜면 키를 넣는 칸이 맨 위에 뜹니다. 키가 있어야 대화가 됩니다.

  1. console.anthropic.com 에서 새 키를 만듭니다
  2. sk-ant- 로 시작하는 키를 복사합니다
  3. 앱의 키 칸에 붙여넣고 저장 을 누릅니다

키는 이 폰 안에만 저장되고, 대화는 폰에서 Anthropic 으로 바로 갑니다. 중간에 거치는 서버가 없어요. 그래서 앱 파일에는 키가 들어 있지 않고, 각자 자기 키를 넣습니다. 키를 바꾸거나 지우려면 앱 위쪽 열쇠 아이콘을 누르세요.

API 사용료는 키 주인에게 청구됩니다. 키를 남에게 알려주지 마세요.

소스와 빌드 방법은 저장소에 있습니다.
안드로이드 스튜디오로 직접 빌드해도 됩니다.
